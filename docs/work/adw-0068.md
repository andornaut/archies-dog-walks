## Scope

Remove planner paths the shipped runtime never uses, then restructure the mover planning code for readability, structure and speed without changing plans.

## Criteria

- One runtime planning path, with the unused switches, test-only path and exact capacity path removed.
- Mover planning split into focused modules described in `src/README.md`.
- Prepared planner data is frozen once instead of re-serialised before each use.

## Decisions

- A modification of prepared data raises a frozen-object error rather than a serialisation mismatch.
- The adaptive omission guarantee stays measured on the acceptance set, not made structural.
