## Scope

Move the gameplay assets into stable, game-owned prebuilt static archives through game-kit's
group transport (`updateGroup`, `groupedFirstInstall.archiveOnly`), at most 100 groups. Keep the
bootstrap, site pages and resources a page uses directly as loose files. Install only the device's
sound codec. Remove the separate install packs and archive recipes this mode replaces.

## Criteria

- The build reports each loose file and its bytes, the archive bytes and any member bytes stored
  both loose and archived, with a reason for each loose exception; no full loose copy of the
  archived payload ships.
- A fresh install, an installed update from the live build that reuses unchanged groups, offline
  play and saved progress all work, for both sound codecs.

## Decisions

- A few loose files are fine when they serve startup, offline behaviour or the site (user,
  2026-11-24).

## Outcome

Built on game-kit 0.73.0. The build ships 26 groups (12 without a format, 7 each for Ogg and AAC)
as gzip archives totalling 5,305,848 bytes (8,074,585 decoded); the largest is the code group at
1,357,979 bytes decoded and 445,266 encoded. 104 of the manifest's 124 files (7,752,184 bytes)
ship only inside the archives. 20 files (312,103 bytes) also stay loose: the game page and its
static imports, the crash fonts, icons, web manifest and `controls.css`, which a first visit loads
before the router installs, and the two DOM sheet images the site's stylesheets name. The other 33
loose files (256,022 bytes) are the site's pages, code and art, the pointer, the manifest, the
router, `_headers` and the Worker. The origin packs and sound banks are gone; the Worker serves
archive-only files from the compressed group archives.

The kit also writes every archive decoded (26 files, 8,074,585 bytes), a full second copy of the
archived payload. The installed ca76dc5e7-era builds, on game-kit 0.71.0, stage the first grouped
update only from these copies, fetching all 26 once. With them the output is 105 files and
13,948,558 bytes; without them it would be 79 files and 5,873,973 bytes, against 68 files and
7,425,760 bytes for ba8fe02ca.

Measured through a local Wrangler Worker, which compresses by content type as Cloudflare does, a
first install transfers 3,547,839 bytes for Ogg and 3,838,449 bytes for AAC, against 3,589,338 and
3,800,959 bytes for ba8fe02ca. An update between grouped builds fetches only the changed archives
(a one-string change: 2 archives, 447,349 bytes). Browser checks passed for fresh Ogg and AAC
installs, offline relaunch, the update from ba8fe02ca with its save kept, the follow-up grouped
update, and the art gallery for a visitor with no installed build, with no page errors or failed
requests.
