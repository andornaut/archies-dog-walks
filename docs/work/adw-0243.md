## Scope

Move the gameplay assets into stable, game-owned prebuilt static archives through game-kit's
group transport (`updateGroup`, `groupedFirstInstall.archiveOnly`), at most 100 groups. Keep the
bootstrap, site pages and resources a page uses directly as loose files. Install only the device's
sound codec. Remove the separate install packs and archive recipes this mode replaces.

## Criteria

- The build reports each loose file and its bytes, the archive bytes and any member bytes stored
  both loose and archived, with a reason for each loose exception; no full loose copy of the
  archived payload ships.
- A fresh install, an installed update from the live build that reuses unchanged groups, offline
  play and saved progress all work, for both sound codecs.

## Decisions

- A few loose files are fine when they serve startup, offline behaviour or the site (user,
  2026-11-24).

## Outcome

Built on game-kit 0.72.0. The build ships 26 groups (12 without a format, 7 each for Ogg and AAC)
in 8,070,846 bytes of archives; the largest is the code group at 1,354,238 bytes. The output is 79
files and 8,632,591 bytes, against 68 files and 7,423,472 bytes for ca76dc5e7. 104 of the
manifest's 124 files (7,750,083 bytes) ship only inside the archives. 20 files (310,465 bytes) also
stay loose: the game page and its static imports, the crash fonts, icons, web manifest and
`controls.css`, which a first visit loads before the router installs, and the two DOM sheet images
the site's stylesheets name. The other 33 loose files (251,280 bytes) are the site's pages, code
and art, the pointer, the manifest, the router, `_headers` and the Worker. The origin packs and
sound banks are gone; the Worker serves archive-only files from the group archives.

A first install fetches 19 archives: 6,168,840 bytes for Ogg and 6,307,441 bytes for AAC, against
6,069,239 and 6,280,861 bytes of files before. An installed 0.71.0 build stages every archive once
(8,070,846 bytes), since its installer predates format tags; a later update fetches only the
changed archives (a one-string change: 2 archives, 1,360,545 bytes). Browser checks against a
local Wrangler Worker passed for fresh Ogg and AAC installs, offline relaunch, the update from
ca76dc5e7 with its save and walk checkpoint kept, the follow-up grouped update, and the art gallery
for a visitor with no installed build, with no page errors or failed requests.
