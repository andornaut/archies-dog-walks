## Scope

Back returns one layer to the invoking view. Preserve paused play, focus restoration, single-layer dismissal and required choices.

## Criteria

- Help and Logbook opened from Menu return to that same Menu through Back or Escape.
- The page's Menu control returns to the retained Menu without launching a second instance.
- Close, X, Escape and outside dismissal leave only the current Menu.
- Returning from a page opened by Pause keeps the walk paused until Resume.
- Restore the invoking control's focus when it remains available, and preserve mandatory choices.

## Decisions

None yet.

## Outcome

Menu retains its invoking view while Help and Logbook are open. Their Back actions and Menu
control restore the same Menu. Close on a Menu over Help leaves Help open. Overlay callers
restore focus to an available invoking control after their native view is painted again.
Pause and required-choice callbacks retain their existing behavior.
