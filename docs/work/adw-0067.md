## Scope

Port every art generator, the sound and music generators, the font builder and the previews from
Python to TypeScript on art-kit, then remove the Python tools and the Aseprite sources.

## Criteria

- A parity harness proves identical outputs before the Python tools are removed.
- `build.ts --check` rebuilds every set in dependency order and diffs it without git.

## Decisions

- Sprite sheets export through art-kit, so Aseprite is no longer a source.
- Art builds run in the gate image.
