## Scope

An open game checks for a new version whenever the start screen appears, so a long-open tab sees the update offer without a reload.

## Criteria

- Each arrival at the start screen runs the update check through the kit's registration and offer calls.
- A test covers the start screen's registration and offer calls.

## Decisions

- Check on return to the start screen, not on every foreground resume.
