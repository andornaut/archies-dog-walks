## Scope

once. Preserve the appropriate parent, pause state, input guards and focus
return. Keep mandatory choice cards nondismissible.

## Outcome

Browser checks covered Menu, Pause, Settings, Details, Purchase, Reset Save,
Cheats, End walk and badge dialogs. Logbook badge details and Install
instructions now restore focus to the original control after the child
closes. Quit X passed with an emulated standalone window. A live Update X
closed the offer without navigating, activating it, or modifying the save.
