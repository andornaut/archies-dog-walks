## Scope

Use the checked grouping of short effects, UI surfaces, fonts and site
art. Alias identical icon bodies by digest. Keep independently updated
music tracks, major code bundles and road atlases in their own files.

Use individual-file updates and keep the complete install manifest under
100 entries. Install only the sound banks for the device's codec. Music
tracks and independently updated assets retain their own URLs.

Preserve exact member bytes and existing URLs for supported installed and
workerless browsers. Verify fresh Start, offline relaunch, the website
and game pages, and a staged update before removing loose originals.

## Decisions

Use the existing Worker to serve packed assets at their original URLs.
The release includes the current build and its required assets. Verify
both sound codecs and offline play before shipping the new output.
