## Scope

Reduce the long frame intervals in a representative Archie active-play workload.
Use current source, a fixed replay and a consistent browser and renderer.
Keep existing gameplay, appearance, save behaviour and offline play.

## Criteria

- Record exact source, replay, browser, renderer and capture settings before
  choosing a change. Repeat the baseline if older samples are incompatible.
- Identify a material recurring cost with matched profiling. Preserve the
  earlier rejected rendering experiments as evidence.
- Alternate repeated baseline and candidate runs in the same environment.
  Preserve raw intervals, nearest-rank p99 for each run and run-to-run variation.
- Demonstrate a reproducible reduction of at least 10% in active-play
  frame-interval p99. Report the limits of the tested environment.
- Pass the affected contract checks and production build. Deliver the checked
  revision through the existing release process.

## Decisions

- D1 (user, 2026-11-27; answers q-archie-p99-presentation): Keep Archie’s current visual timing while pursuing the p99 target.
- D2 (user, 2026-11-27; answers q-archie-p99-pacing-test; supersedes D1): Test different renderer pacing in isolation. Keep the production visual timing while evaluating frame timing, motion and input.
