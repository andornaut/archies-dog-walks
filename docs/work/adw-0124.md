## Scope

Home shows Menu and the walk shows Pause, each a vertical list of equal-width actions in one shared width; mute stays visible on every screen.

## Criteria

- Menu holds Help, Logbook, Settings and an eligible Exit; Pause holds Help, Settings and End walk.
- No visible number prefixes; keyboard shortcuts and focus order are unchanged.
- Mute is shared across loading and crash screens.

## Decisions

- Pause appears only during active gameplay; Menu elsewhere.
