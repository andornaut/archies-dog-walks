## Scope

The adw-0251 proposals that change pixels: one label placement rule for button and backed labels
(P7b, P7c); unified Settings, Cheats and page rows, separators, icon gaps, row columns and footer
gap (P8); the standalone Sound control matching the top bar (P10); one crash and website sheet with
shared palette tokens (P11); and the Game Kit spacing tokens (adw-0252). Art prepares before and
after captures with a recommendation for each change and for the open decisions: the disabled,
secondary pressed and primary bevel looks, badge focus fill, display heading shadow centring, page
heading x, stacked or row confirmations and the footer gap. Tech builds only what the user approves
from those captures.

## Criteria

- Each approved change matches its approved capture.
- Equivalent components follow one placement rule.

(`game-coordinator/var/handoffs/games/archies-dog-walks/art/resources/adw-0257/`) on 2026-11-25:
