## Scope

The approved findings of the first improvements review: small fixes, a maintained planner acceptance
harness, zone spawn guarantees derived from weights, one card-money key, one home per rule in the
docs, ID renames, the `moverShare` comment, an explicit upgrade draw order, and badge, upgrade,
gear, hint and perk text filled from data.

## Criteria

- `npm run planner:acceptance` runs the bounded acceptance batch on plain Node.
- Each positive-weight kind gets one zone guarantee, and planned layouts are unchanged.
- One `cardOptionCost` key replaces the per-card $20 money keys.
- Each gameplay rule has one home in the docs.
- Stale upgrade, tuning and card option IDs match their names.
- Upgrades draw from an explicit ordered list, and seeded draws keep their order.
- Badge goals and upgrade, gear, hint and perk text fill their numbers from data.

## Decisions

- `moverShare`: only its comment changes, describing it as the authored-movement chance; its values
  stay.
- The upgrade draw order is an explicit ordered list.
- The ID renames bump the save version, shared (version 24) with the game-kit achievements adoption.
