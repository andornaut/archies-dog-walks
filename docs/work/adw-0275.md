## Scope

Show the settled selection state when an item is picked or dropped in the Start
picker or Pet shop. Keep the existing colours and marks.

## Criteria

- Pointer and keyboard activation show the same selected state immediately.
- Selection does not blink, pulse, fade or hop.
- Focus, active press, holds, refusal and purchase feedback retain their paths.
