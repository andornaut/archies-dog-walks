## Scope

Use the same switch and state-label layout on Cheats and Settings. Make ordinary
action labels slightly smaller across the game.

## Criteria

- The state label sits directly below its switch on the same horizontal centre.
- Switch rows share layout rules for labels, descriptions and controls.
- High Park and Cabbagetown fit side by side with complete labels.
- Action labels use one shared size across ordinary buttons and keep their ink
  centred. The minimum press area stays the same.
