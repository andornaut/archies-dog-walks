## Scope

Enable every visible cheat from Start and Pause. Remove the Next walk heading.
During a walk, switch immediately to the selected neighbourhood, toggle
Invincible owners on the current pack, and apply unlocks and bank grants to
the current cheat session.

## Criteria

Starting a neighbourhood abandons the unfinished section without a completion
payout or a stale choice. Earlier completed sections and the current pack carry
over. The selected neighbourhood can be restarted. Reset save retains its own
eligibility and confirmation.

## Decisions

Start configures the neighbourhood and invincibility for the walk it launches.

## Outcome

Start and Pause expose the same cheat controls. Local Chromium verified
Start selection, an immediate live neighbourhood switch and restart, and
invincibility toggling during the walk. Session tests cover a held final
neighbourhood and a pending fork.
