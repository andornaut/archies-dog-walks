## Scope

Ordinary screens, overlays, choice cards and the walk HUD render directly into DOM views on game-kit's shared UI modules, replacing the canvas mirror.

## Criteria

- Native DOM is the sole renderer for ordinary game UI; Phaser draws the world, Boot art and Help illustrations.
- Native and canvas controls share press admission.
- The unused canvas UI renderers are retired.

## Decisions

None beyond the scope.
