## Scope

Forward the build identity supplied by Game Kit through Archie's precache
wrapper to the emitted build pointer and manifest.

## Criteria

- A clean release build emits its exact Git commit in the pointer and manifest.
- Local builds without an eligible source identity retain the shared fallback.
- The build still uses the shared clean-source identity check and existing
  group archive and update behaviour.

## Outcome

Released in `3d454a66f`. The live build pointer and manifest both matched the
exact checked release files and reported the published commit as their build ID.
The build kept 26 update groups.
