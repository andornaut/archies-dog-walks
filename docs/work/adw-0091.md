## Scope

Menus, overlays, screens and the walk HUD draw in HTML over the canvas in phases; the canvas draws the world.

## Criteria

- Phases ship when green: pause menu, other overlays, start screen, shop, Logbook and end screen, then the walk HUD.
- Font pixels are whole device pixels and every part sits on the art-pixel grid.
- Art reviews each phase before it lands.

## Decisions

- A font pixel is floor(2 x game scale x DPR), so text never overflows its box.
- Focus rings show only on `:focus-visible`.
