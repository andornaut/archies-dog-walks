## Scope

Reduce the bytes and number of files in the production art build by improving
packing and metadata. Keep authored art, image fidelity and audio compatibility.

## Criteria

- Compare art bytes, art file count and total build size with the production
  baseline on `5a19bc473`.
- Preserve frame names, order, durations, tags, trim and sampling exactly.
- Preserve the gallery, development loading and content-hashed offline builds.

## Decisions

None yet.

## Outcome

Production emits one compact art manifest with its atlas index, and one lossless
WebP page for the nearest-filtered home and run art. The dev manifest stays in
source format. Existing frame names, pixels, animation timing, and offline
audio alternatives are preserved.
