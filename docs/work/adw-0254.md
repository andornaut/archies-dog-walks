## Scope

Audit the spawn planner, zone generation and other procedural rules against the cross-game
procedural policy and fix each gap. Known gap: exact construction (the witness search without a
delivery floor) is a mode only unit tests run, which the policy's runtime-path-only rule excludes.

## Criteria

- Every procedural entry point is pure, takes context first and the subject last, and reads only
  injected entropy and named Game Kit streams.
- No test-only planner modes remain; tests exercise the runtime path.
- Behaviour-preserving changes show identical output; behaviour changes are measured one rule at a
  time against the planner acceptance batch.

## Decisions

- Split the planner's shared streams into one named stream per purpose now: build the split beside
  the current path, measure it with the planner acceptance batch and Gameplay's review, then switch
  and bump the save version, resetting older saves (user, 2026-11-25).
- The split failed the acceptance batch only in Yonge Street's Rush hour (71 of 72 complete, one
  plan at the full search budget, four over the 75% headroom). Gameplay tunes that zone's values
  until the batch passes on the split streams, then the split switches with the whole save version
  bump (user, 2026-11-25).

## Outcome

The planner builds only its runtime path: exact construction, the seed-0 planning wrapper and the
quota planning error are gone, planner refusals are typed outcomes with reasons, ports and work
fields runtime supplies are required, observers sit left of the subject, and each spawn board check
is one predicate returning its refusal. Every planner purpose draws from its own named stream, with
the save version at 28, and Yonge Street's moving minor obstacles at 62 keep Rush hour within the
search budget. Gameplay's official acceptance batch on 129f2ef89 passed 72 of 72 plans with a peak
of 62.4% of the per-attempt budget (2026-11-25). Two gaps remain outside this item: the lower
feasibility modules still take boolean checks with an observer, and `prepareSlotKind` serves tests
of the lazily built motion index.
