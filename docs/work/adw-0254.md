## Scope

Audit the spawn planner, zone generation and other procedural rules against the cross-game
procedural policy and fix each gap. Known gap: exact construction (the witness search without a
delivery floor) is a mode only unit tests run, which the policy's runtime-path-only rule excludes.

## Criteria

- Every procedural entry point is pure, takes context first and the subject last, and reads only
  injected entropy and named Game Kit streams.
- No test-only planner modes remain; tests exercise the runtime path.
- Behaviour-preserving changes show identical output; behaviour changes are measured one rule at a
  time against the planner acceptance batch.

## Decisions

None yet.

## Outcome

Exact construction, the seed-0 planning wrapper and the quota planning error are removed, and the
witness search takes its work meter first. The 72-plan acceptance batch gives byte-identical plans
and certificates before and after. Open gaps that would change generated walks: the per-zone
`spawns` and `movers` streams serve several purposes each, and walk-time card draws share the
run's `cards` stream. Open gaps that would not: two planner throws and one blocked result without
a reason, optional ports and work fields only tests leave unset, two observers placed after the
subject, spawn board checks that report reasons through a callback, and `prepareSlotKind`, which
tests of the lazily built motion index still need.
