## Scope

Audit every screen, modal, page and HUD element for controls that bypass the design system's
shared components (buttons, form fields, rows, panels) and for alignment that isn't derived from
one consistent rule. Propose refactors that make component layout simpler and consistent. The
audit changes no code; each refactor it proposes is its own item for approval.

## Criteria

- A complete inventory of one-off controls and inconsistently aligned elements, each with its
  file and the shared component or rule it should use.
- Ranked refactor proposals with scope, risk and the visual change each would cause.

## Decisions

- Tech does every pixel-identical refactor the audit proposes, as adw-0255 (user, 2026-11-25).
- Visible changes and the open look decisions go to Art for before and after captures with a
  recommendation, and the user approves from the captures, as adw-0257 (user, 2026-11-25).
- The crash screen and panel test defects are fixed now, as adw-0256 (user, 2026-11-25).

## Outcome

92 findings: 26 duplicate implementations, 22 inconsistent rules between similar components, 16
ad hoc alignment offsets, 7 one-off controls, 7 restated geometry values, 5 dead code paths, 5
defects or test gaps and 4 documentation conflicts. Every DOM button already comes from
`createGameButton` except the choice-card option, the speech bubble and the gear badge; every top
bar comes from `createNativeTopSection`; footers follow the centring and primary-right rules. No
proposal needs a Game Kit change.
