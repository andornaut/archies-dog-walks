## Scope

The crash screen's Tiny5 WOFF2 keeps only the glyphs its text can use, through art-kit's
`subsetWoff2`, with a build check that every crash screen string is covered.

## Criteria

- The crash font ships subset, and the build fails on any crash string glyph it lacks.
- Text outside the subset still falls back to the system monospace font.
- The font's OFL licence travels with it unchanged.
