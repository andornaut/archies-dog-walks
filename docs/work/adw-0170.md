## Scope

The build stops copying the duplicate art exports into `dist/art`, and the art gallery reads the
hashed game art through the built manifest.

## Criteria

- `dist/` holds each art file once, and nothing the runtime does not reference.
- The art gallery still shows every asset.

## Decisions

- The build copies only the pages under `art/` and the files they or the built pages and CSS
  name; a named file missing from `public/art/` fails the build.
- `art-files.json` maps each `/art/` path to its hashed URL, and the gallery reads every file
  through it, falling back to the raw path for the native-only keys.
- An unreadable atlas manifest now draws placeholders instead of raw `/art/` copies.

## Outcome

Shipped in ce18ab6e7 and 44748a97e: `dist/` holds 867 files (9.4 MB), down from 4,288 (19.6
MB), and the gallery makes about 109 requests instead of 3,443.
