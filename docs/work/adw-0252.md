## Scope

Space controls with the Game Kit tokens applied by the containing group: 16 px between
side-by-side buttons, 8 px between stacked standard buttons and 24 px between small buttons, with
no per-control padding cancelled by negative margins. Art pairs each token with Archie's pixel-grid
geometry through the kit components.

## Criteria

- Every button group takes its spacing from the kit tokens; no local gap constants remain.
- Visible changes are approved from before and after captures.

## Decisions

Use the spacing roles and named exceptions approved in adw-0257.

## Outcome

The game reads the 16, 8 and 24 px button gaps from Game Kit. Modal actions,
stacked controls, picker tiles, Cheats columns, and small top-bar and tab
buttons use their approved spacing roles. Art accepted the visible changes
with the adw-0257 captures, including the before-and-after top bar comparison.
