## Scope

Keep the root README short and make the documentation indexes explain their
scope and navigation. Move useful details to their owning document.

## Criteria

- Root README describes the game and links to the docs.
- Each documentation index explains its purpose, contents and actual subfolders.
- Existing working links, generated indexes and gameplay categories survive.
