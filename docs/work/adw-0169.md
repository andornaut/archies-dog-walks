## Scope

Consolidate the native interface's own-file art into one sheet per asset set with frame data.
Art exports the sheets and their manifest; Tech loads, readies and draws them.

## Criteria

- Each set ships as one sheet within the texture limit verified on mid-range Android.
- The DOM art reads frames from the sheet manifest, readiness is per sheet and the precache
  lists the sheets instead of the own files.
- Rendered pixels are unchanged.
