## Scope

Neighbouring button faces use the kit's gaps: 16 px side by side, 8 px stacked, 24 px where either face is smaller.

## Criteria

- Start screen tiles, top bar faces, tabs, settings rows and badge rows follow the gaps.
- The walk bar, choice cards and badge strip are named exemptions.

## Decisions

- Compact 128 px buttons count as standard and use 16 px.
- Every vertical stack uses 8 px.
