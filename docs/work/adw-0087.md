## Scope

`make check`, `make lint`, `make test` and `make build` run in isolated, non-root containers through `tests/container/run`, `Dockerfile` and `check`.

## Criteria

- The npm scripts alias the Make recipes.
- The gate runs the tests through `npm test` alone, which sets the worker count.

## Decisions

- Optional Make and container metadata interfaces are removed.
