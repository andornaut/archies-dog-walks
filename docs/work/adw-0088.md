## Scope

A walk begun with the dev panel's Start at treats its start zone as the first zone.

## Criteria

- The walk banks, sets best walks, finishes and unlocks walkers like any walk.
- The zones before the start zone count for nothing.

## Decisions

- No special banking for skipped zones.
