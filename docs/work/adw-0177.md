## Scope

A run URL can turn on Invincible owners, as it sets the speed, so a reproduced walk and the Art
screen grabs reach the same walk the Cheats modal sets up. The Art tools move off the retired
Dev panel.

## Criteria

- `invincible=1` in a run URL turns on Invincible owners for that walk, starts a cheat session as
  every run parameter does, and Copy run link writes it.
- `art/tools/pixel.ts` and `art/tools/home_grabs.ts` work against the Cheats build, and the
  export no longer carries the retired dev storage keys.
