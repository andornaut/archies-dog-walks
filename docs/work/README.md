# Work items

Each request has a stable `docs/work/<id>.md` record for scope, decisions and outcome. Live progress and delivery evidence remain in the coordinator's work store.

The [work-item reference](../reference/work-items.md) defines the metadata, milestones, ownership and integration convention.
