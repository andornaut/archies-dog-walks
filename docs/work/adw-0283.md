## Scope

Add a visible Controls section to Archie's landing page using the existing site
style and the game's supported inputs.

## Criteria

- Use concise semantic tables with Action and Input column headers for gameplay
  and menu controls.
- Verify keyboard bindings and relevant pointer and touch gestures against the
  current game source.
- Keep the complete tables readable at narrow viewport widths.
- Preserve gameplay bindings, navigation, existing site controls and artwork.
