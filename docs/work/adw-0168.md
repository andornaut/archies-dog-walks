## Scope

Apply the shared Installs and Updates rules through game-kit's shared loader, with no local
loader fork.

## Criteria

- A first install downloads the complete build with determinate progress and verifies it before
  play; the installed game then plays fully offline.
- One loading screen covers the install and boot.
- An update downloads only changed files in the background and stages until complete; switching
  needs no further download.
- A staged update activates silently at launch, before gameplay and save initialization.
- An update that finishes during a session shows an Update now prompt wherever the player is: it
  pauses play, saves and switches at once. Dismissing it continues play, and the next launch
  applies the update silently. The home-screen-only update offer is removed.
- A failed background update never shows Loading failed or interrupts play.
