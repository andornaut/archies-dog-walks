## Scope

Use the same Game Kit Back guard and departure API as the other games.
Archie owns foreground routing, the prompt and its wording.

## Criteria

- Platform Back on eligible fresh and returned Start opens Exit or Cancel.
- Cancel stays on Start and leaves the next Back armed.
- Exit requests one native departure when the shared guard can leave.
  An unavailable or failed departure preserves Start.
- Foreground Back closes one layer and active gameplay keeps its Pause
  handling. Escape, letterbox taps and explicit Quit keep their own paths.
