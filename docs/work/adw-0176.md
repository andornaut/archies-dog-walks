## Scope

The home page and the site stylesheet name hashed art files, so the eleven files that ship both
raw and hashed ship once.

## Criteria

- `pages/index.html` (the dog portraits and the owner face) and `public/nav.css` (the check mark)
  use the hashed art URLs.
- `dist/` holds no art file twice.

## Decisions

None yet.

## Outcome

The production home page and navigation stylesheet reuse frames from existing hashed DOM sheets.
The build omits the eleven redundant raw files, saving 12,630 bytes without adding image output.
The output check verified the frame positions and exact pixel equality for every replaced asset.
