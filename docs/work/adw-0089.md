## Scope

Settings' install steps use shorter wording that fits their card, and the walker's one-time install
suggestion on the start screen skips Firefox on desktop.

## Criteria

- Every browser's install steps fit their card at full size.
- The walker's bubble never suggests installing in Firefox on desktop.
- Settings tells Firefox desktop players that Firefox can't install the game, so open it in Chrome
  or Edge.

## Decisions

- Shorter install-step wording.
- The install suggestion skips Firefox on desktop, which cannot install the game.
