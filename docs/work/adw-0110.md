## Scope

Assets load cache first; a new version downloads into a complete isolated cache and activates only on Update now or a fresh launch.

## Criteria

- A failed stage never activates, and offline boots run the complete cached version.
- Game startup waits on the staged-update launch gate.

## Decisions

- Automatic activation only for a newer save.
