## Scope

On a genuine in-app return to Start, request an ordinary update check via the
published game-kit wake API. Preserve cooldown, foreground and online checks,
the current document's active build and save, and explicit acceptance of a
staged update.

## Decisions

None yet.

## Outcome

On deployed e622f0f8, returning from a walk to Start requested the new
build and staged it while the old document stayed active. One Update now
press loaded the new build through one navigation and preserved the save.
This browser check covered the return to Start route.
