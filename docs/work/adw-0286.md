## Scope

Remove the homepage navigation and footer and retire the public Tuning and
Gallery pages. Keep the gameplay asset URLs, manifests and pipelines that the
game still uses.

## Criteria

- Play comes before Install in DOM, visual and keyboard order at narrow and
  desktop widths.
- The homepage keeps the Controls tables and existing Play and Install actions.
- The production build contains no public Tuning or Gallery page or obsolete
  site links. Game assets and the in-game interface still work.
