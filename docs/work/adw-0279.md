## Scope

Fit Settings descriptions using a shared word-wrapping rule that accounts for the
right-aligned switch and its state label.

## Criteria

- The Sound description fits on one line at its full size.
- Longer descriptions wrap at word boundaries and stay clear of the control stack.
- Row heights and rendered text use the same fit. Toggling a switch preserves its row height.
