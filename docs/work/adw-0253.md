## Scope

Replace each locally built card, header, close button, switch, form row, pager, action group and
HUD disc that adw-0251 finds with its Game Kit component, requesting missing components from Game
Kit. Each pattern keeps one layout rule: one centring method, one title pattern and one footer
pattern.

## Criteria

- No local implementation of a component Game Kit provides remains.
- Restructurings are pixel-identical; visible changes are approved from captures.

## Decisions

- A held Settings switch row dips every part by Game Kit's whole art pixel, which at 390x844 DPR 3
  sits up to 3 device pixels higher than the earlier per-part dip (user, 2026-11-25).
- Settings' slider comes from a Game Kit slider, requested from Game Kit; Archie keeps its own
  until the kit ships one (user, 2026-11-25).
  Scope follows the adw-0251 findings.

## Outcome

Pages, form rows, switches, sliders, the Help pager and square HUD controls use Game Kit
components. Action groups use Game Kit arrangement with the existing button faces. Ordinary
cards use its frame, title, content, footer and close slots with the existing modal lifecycle.
Their authored pixel geometry, close target and focus return match the prior layout.
