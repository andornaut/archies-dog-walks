## Scope

A save written by a newer version forces the update with no prompt; offline, the save is untouched and a short message says the update installs when online.

## Criteria

- The game updates itself for a newer save through game-kit's `requireNewer`.
- Offline, the older game writes nothing to the save and retries when back online.

## Decisions

- The message says what will happen, not why.
