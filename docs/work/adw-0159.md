## Scope

A press on a discrete control becomes a hold after 500 ms, as the shared hold policy sets for every
game.

## Criteria

- `holdSeconds` is 0.5.
- A press held for 500 ms is a hold; one released a millisecond sooner is a tap.
- The walk's explain holds (effect icons, debuff bars and dog cards) use the same timing.

## Decisions

- A hold on a discrete control fires after 500 ms in every game.
- The walk's explain holds target controls, so they count as discrete.

## Outcome

Rule, value and export `5f240fc6c`, and Tech source `539c99bb5`, which reads the live hold time for
native control holds. The rule lives in
[Teaching, sound and settings](../design/gameplay/design.md#teaching-sound-and-settings) (Buttons) and
the value in `src/data/tuning.ts` (`holdSeconds`).
