## Scope

Keep keyboard accessibility and forced-colours visibility while replacing generic browser focus decoration on game controls.

## Decisions

None yet.

## Outcome

Custom-painted controls and standalone mute use cyan focus bands with ink keylines. Seed fields retain native editing and selection. Forced-colours focus uses the system Highlight and Canvas colours. Focus decoration leaves pointer appearance and selected, pressed and disabled control states intact.
