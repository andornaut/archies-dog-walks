## Scope

Use the existing dismissal action as the sole visible dismissal control when
each decision action already dismisses its dialog. Preserve Escape, backdrop
and browser Back handling, one-layer return, focus and mandatory choices.
Keep the existing dismissal controls on ordinary Close-only cards.
