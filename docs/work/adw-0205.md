## Scope

Keep the top-right X and one existing cancellation in the action area.
Route X to the same one-layer cancellation and restore focus. Preserve
Escape, backdrop and browser Back handling. Preserve required choices with
no valid cancellation and report the current actions for reconciliation.

## Decisions

None yet.

## Outcome

Decision dialogs keep one cancellation action in the footer. Eligible X
controls restore the invoking focus, including after a touch hold on Start
and in Pet Shop. Deployed in `d590a35e`.
