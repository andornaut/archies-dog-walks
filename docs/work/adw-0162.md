## Scope

Short design summaries in `docs/design/<area>.md`, one work file per approved task in
`docs/work/<id>.md` and the convention in the [work-file README](README.md). Finished approved
work since 2026-11-04 is backfilled for Art, Gameplay and Tech.

## Criteria

- Each design area has an owner, a summary that links its topic docs and an index table of ID,
  title and link, with no status column.
- Each work file has the convention's front matter and the Scope, Criteria, Decisions and
  Outcome sections.
- Nothing under `docs/` is served or deployed.

## Decisions

- The topic docs stay where they are and remain the detailed reference.
- Live progress stays in the protocol state root; a work file records only milestones.
- Each role writes its own area summaries and work-file bodies; Tech allocates IDs and edits the
  index tables on `main`.
- Work before 2026-11-04 is not backfilled: no approval references exist for it.

## Outcome

Design areas art, planner, rules, tooling, tuning and ui, with work files adw-0001 to adw-0162 in `docs/work/`.
