## Scope

Apply the shared Pause and Menu navigation rules to the Start screen and the walk.

## Criteria

- The Start screen shows Menu and an Exit button; Exit appears only where exiting works in the
  current runtime, detected at runtime.
- Pause and Menu are one modal. On the Start screen its bottom button is Close; in the walk it is
  Resume. The bottom button is the primary action in the primary style.
- In the walk, Back to title sits directly above the bottom button; the Start screen has none.
- Every other button in the modal is ordered alphabetically by label.

## Decisions

- Exit shows only in an installed app window a script can close, so leaving never navigates
  elsewhere; a browser tab never offers it (user, 2026-11-18, game-policies c14d027).
- The Menu has no Quit, since the top bar's Exit leaves (user, 2026-11-18).
- In a browser tab, back on the bare Start screen does nothing (user, 2026-11-18).
- The leave label stays Quit in every game (user, 2026-11-18).
- The other Menu entries were already alphabetical once Quit left; Pause already complied.
