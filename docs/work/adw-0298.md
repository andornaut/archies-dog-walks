## Scope

Use the existing Menu action for Escape on uncovered Start. Preserve the
one-layer dismissal and Pause routes, and document the shared keyboard flow.

## Criteria

- Escape opens Menu on Start and opens Pause during uncovered, pausable play.
- Escape in Settings returns one level. On Pause, another fresh Escape resumes.
- Arrows move focus. Space and Enter activate a focused available control or
  flip a focused switch row once.
- Required choices, repeat guards, slider and editor controls, and browser
  Back preserve their existing behaviour.
