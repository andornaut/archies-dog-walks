## Scope

Group cohesive modules in the Runner, Scenes and Home areas. Review shared conventions
with the other games and keep callers on deliberate public interfaces.

## Criteria

- Reduce direct file counts in the selected crowded directories through cohesive groups.
- Preserve source bands, supported caller imports, authored content and game behaviour.
- Keep adjacent tests and source documentation aligned with the new paths.
- Verify scoped changes in isolated checks and record the cross-game comparison.

## Outcome

| Area   | Private capability folder | Direct files before | Direct files after |
| ------ | ------------------------- | ------------------: | -----------------: |
| Home   | `details/`                |                  85 |                 78 |
| Runner | `src/runner/walk/`        |                 166 |                140 |
| Scenes | `src/scenes/boot/`        |                 135 |                124 |

The nested folders keep public entry points and source bands intact. Helpers use direct imports
inside their area, and tests stay with the capabilities they exercise. These choices follow the
same conventions as Chibi's rule folders and Ada's model capability folders. The folders keep
their game-specific names.
