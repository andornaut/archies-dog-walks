## Scope

Remove tests that repeat a surviving regression check and reduce avoidable setup. Use
data-driven cases where they clarify meaningful input differences.

## Criteria

- Record executed case counts and wall time before and after under the same isolated settings.
- Identify the remaining checks that protect each removed behaviour and disclose accepted losses.
- Preserve distinct edge cases, application behaviour and required delivery checks.

## Outcome

The isolated Node 24.22.2 suite ran 7,236 tests in 164.55 seconds, down from 7,239 tests
in 195.47 seconds with the same two-worker configuration and 441 files.

- The taxi check tries the known witnesses for both road edges before the original seed search.
- Scenery checks share one seeded replay with all layers active. They still compare full
  session state and events against an independent plain replay and check struck-item re-entry.
  The separate single-layer replays were retired.
- A duplicate persistent-debuff case was removed. The detailed cost test still covers counting
  while the debuff is active, and the acquisition and expiry boundaries remain separate.
