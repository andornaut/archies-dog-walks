## Scope

Closing the Update available prompt, Settings or another overlay over the Start screen returns
keyboard focus to the control that held it, instead of the page body.

## Criteria

- After Cancel, the X, Escape, back or a tap outside, the Start screen control that was focused
  before the overlay opened is focused again, and arrow-key focus is unchanged.

## Decisions

- The Start screen's native home session holds the id of the focused Start control as the screen
  pauses under an overlay, and keeps it through redraws while paused (Cheats changes, the
  Settings close redraw) until the first paint that takes input focuses that control again.
  Every overlay that pauses Start (the Update available prompt, Settings, the Menu, Cheats, Help,
  the Logbook and the Pet shop) shares the one path; detail cards keep their existing restore of
  the item they describe.
- As for any redraw, the restore applies only when focus at that paint is on the page body or has
  not moved since the redraw; the arrow-key focus ring is unchanged.

## Outcome

Shipped in ea30dd517: Start saves the focused control when it pauses and focuses it again on
the first paint that accepts input, for every overlay and close route.
