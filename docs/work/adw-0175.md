## Scope

Apply the shared Saves and cheats rules: the Dev panel below the game is retired into a Cheats
modal opened from Settings, with the cheat list Gameplay records.

## Criteria

- Settings shows Open Cheats beside Back, in browser tabs only.
- Cheats is a large scrolling modal with Run-only and Save-changing groups.
- A full Reset save clears the save, badges included.
- An FPS counter toggle shows the rate at the top left.
- No cheat touches achievements or statistics.
