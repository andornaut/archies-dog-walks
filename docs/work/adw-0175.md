## Scope

Apply the shared Saves and cheats rules: the Dev panel below the game is retired into a Cheats
modal opened from Settings, with the cheat list Gameplay records.

## Criteria

- Settings shows Open Cheats beside Back, in browser tabs only.
- Cheats is a large scrolling modal.
- Any cheat starts a cheat session in which nothing is saved, earned or banked; returning to the
  Start screen ends it, and Continue then loads the save from before the session.
- Reset save, Show tips again and the FPS toggle are not cheats; a full Reset save clears the
  save, badges included.
- An FPS counter toggle shows the rate in the device viewport's bottom right corner, inset from
  the safe area and drawn above everything, letterbox bars included.
- No cheat touches the save, achievements or statistics.

## Decisions

- A walk that uses any gameplay cheat writes nothing to the save, as a replay does: no
  checkpoint, banking, statistics, records or badges. Hit boxes, dev stats and the FPS counter
  only draw and do not count. This supersedes adw-0088's Start at banking (user, 2026-11-18).
- Cheats never write the save: there are no save-changing cheats and no boot-time queue of save
  edits (user, 2026-11-18, game-policies 0b35005).
- The cheat list and modal layout follow `gameplay/cheats.md`.
- The session starts at the first cheat and lives only in memory; returning to the Start screen
  from a walk, or a reload, restores the save from before it. No badge is earned in a session.
- Open Cheats sits beside Close, since Archie's Settings ends in Close.
- Hit boxes and the dev stats overlay are removed (user, 2026-11-18).
