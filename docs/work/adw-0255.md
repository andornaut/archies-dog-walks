## Scope

The adw-0251 proposals that change no pixels, each landed as its own gated change, in this order:

1. Delete the dead canvas interface code and stale geometry, and point the text-role tests at the
   live panels (P1).
2. One refusal cue for every refused control (P2).
3. One shared DOM parts module: fills, frames, colour strings, ink measurement and one button
   reset (P3).
4. One page template with one scrollbar and one Back derivation (P4).
5. `arrangePanelActions` as the only action-group builder (P5).
6. Name every restated size as a layout token (P6).
7. Title-font labels centre by ink, not advance (P7a).
8. Shared walk HUD parts: debuff track, road banner and press dip (P12).
9. The choice-card option on `createGameButton` (P9), after the others because of its hold and
   release behaviour.

## Criteria

- Every step renders pixel-identical captures of the screens it touches.
- Each step deletes the duplicates it replaces.

## Decisions

- The speech bubble keeps its own button, with the shared reset class and fill cues, as a named
  exemption: the shared button paints its focus fill over the whole bubble (user, 2026-11-25).
