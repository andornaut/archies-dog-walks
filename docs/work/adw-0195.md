## Scope

After opening a detail card by holding a picker tile, the first separate press on its Close control dismisses the card. The release of the opening hold cannot activate the new card. Keep the existing dismissal and keyboard behaviour for other views.

## Decisions

None yet.

## Outcome

Native input admission counts only held canvas-origin pointers as canvas input.
The opener release leaves the detail card open and the first separate Close
press dismisses it. Genuine canvas input and native press leases stay exclusive.
