## Scope

Split the Test workflow so a change confined to `docs/` runs only Lint and the AI attributions
scan.

## Criteria

- A Changes job classifies each push or pull request; Lint always runs.
- Test runs unless every changed path is under `docs/`, so a failed or unclassifiable diff runs
  everything.
- Changes is a required check, because a skipped required run counts as passing.
- The game never serves or deploys `docs/`.

## Decisions

- Test is gated on `!cancelled() && needs.changes.outputs.code != 'false'` rather than on
  `code == 'true'`, so a crashed Changes job cannot skip it.
