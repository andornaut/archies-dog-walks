## Scope

Cheats are tools that act on the real save. Remove the cheat session: cheats, cheated walks and
walks started from a run link save, bank and earn badges as normal play. Reset save in Cheats
stays the way back to a new save. Fix the Add money cheat, which shows no effect.

## Criteria

- Adding money from Cheats during a walk, then ending the walk, shows that money in the bank on
  the Start screen, and it is still there after a reload.
- Every other cheat's change persists the same way; no cheat or run link sets the save aside.

## Decisions

- No cheat session: a cheated walk and a run-link walk save and earn badges like any walk
  (user, 2026-11-24).
