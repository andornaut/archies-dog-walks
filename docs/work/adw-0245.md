## Scope

Cheats are tools that act on the real save. Remove the cheat session: cheats, cheated walks and
walks started from a run link save, bank and earn badges as normal play. Reset save in Cheats
stays the way back to a new save. Fix the Add money cheat, which shows no effect.

## Criteria

- Adding money from Cheats during a walk, then ending the walk, shows that money in the bank on
  the Start screen, and it is still there after a reload.
- Every other cheat's change persists the same way; no cheat or run link sets the save aside.

## Decisions

- No cheat session: a cheated walk and a run-link walk save and earn badges like any walk
  (user, 2026-11-24).
- Add money adds to the bank, during a walk too, and is written at once (gameplay/cheats.md).
- Next walk choices (Start at and Invincible owners set from Start) still turn off once the walk
  they start returns to Start: they set up that walk, and are not save data.
- The save's shape is unchanged, so the save version stays.

## Outcome

Shipped in 6402d5f14 and 026e799d2. Add money showed no effect because the first cheat started a cheat session: the grant changed
only the session's save in memory, the walk's HUD shows the walk's cash rather than the bank, and
the Start screen after the walk ended the session and restored the save from before the first
cheat. The cheat session is gone: grants write through the profile at once, cheated and run-link
walks save and earn badges, and Reset save keeps its confirmation. Local Chromium verified Add
$1,000 during a walk, End walk, the Start screen at $2.5K from $1.5K, and the same after a reload.
