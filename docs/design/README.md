# Design

Each area has a short design summary and an index of its work items. The topic docs in
[art/](../../art/README.md), [gameplay/](../../gameplay/README.md), [src/](../../src/README.md)
and [docs/](..) remain the detailed reference. Work items and their convention are in
[docs/work/](../work/README.md). Each area's owner writes its summary and its work-file bodies;
only `main` edits the index tables.

| Area                  | Owner    | Covers                                                                                   | Topic docs                                                                                   |
| --------------------- | -------- | ---------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------- |
| [art](art.md)         | Art      | Art pipeline, style guide, palette, lights, roadside and verge data, icons and inventory | [art](../../art/README.md)                                                                   |
| [planner](planner.md) | Gameplay | The spawn planner contract and qualification                                             | [planner work](../planner-work.md)                                                           |
| [rules](rules.md)     | Gameplay | Rules, screens, controls and player voice                                                | [design](../../gameplay/design.md)                                                           |
| [tooling](tooling.md) | Tech     | Checks, the container, CI, the build, dependency pins, delivery, deployment and the docs | [README](../../README.md), [src](../../src/README.md)                                        |
| [tuning](tuning.md)   | Gameplay | Targets, tuning, playtesting and undecided ideas                                         | [gameplay](../../gameplay/README.md), [ideas](../../gameplay/ideas.md)                       |
| [ui](ui.md)           | Tech     | The HTML interface, modals, layout, fonts and Phaser art loading                         | [src](../../src/README.md), [controls](../../art/controls.md), [layout](../../art/layout.md) |
