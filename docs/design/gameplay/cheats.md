# Cheats

Browser tabs and installed apps offer one **Cheats** entry in the applicable Menu or Pause. The shared [Saves and cheats policy](https://github.com/andornaut/game-coordinator/blob/main/docs/game-policies.md#saves-and-cheats) governs availability and save guards.

## Saving

Cheats act on the real save, as normal play does. Cash and unlocks they grant, and walks played with cheats on, walks started from a run link included, save, bank and earn badges like any other walk. Reset save is the way back to a new save.

## Page

- **Page** is a frameless page titled Cheats under the live top bar, like Help. Its body scrolls when needed and text stays full size. See the [Layout guide](../../../art/layout.md#page-boundsalignment) for interface measurements.
- **Leaving** uses the page Back, Escape or browser or device Back. Each returns to the invoking Menu or Pause and restores focus to Cheats. On the top bar, Menu returns there outside a walk, and Pause returns there during a walk. Outside taps leave the page open. See [Navigation](rules.md#navigation).
- **Order** starts with Invincible owners and Start at, followed by Unlocks and Money side by side. Reset save follows without a section heading.
- **Controls** show On or Off directly below the right-aligned switch. Add buttons are repeatable. All cheats are available from Start and during a walk.

## Cheats

- **Invincible owners** toggles protection against heart costs from bumps and cards. The change applies immediately during a walk. From Start, it applies to the next walk. The label aligns with the left content edge. A horizontal rule separates the switch row from Start at.
- **Start at** shows one button per neighbourhood in game order. From Start, the button sets the starting neighbourhood and route for the next walk. During a walk it immediately selects the chosen neighbourhood within the same walk, including revisits or restarting the current neighbourhood. The walk holds under the new neighbourhood’s banner until that road is ready. Skipped segments give no completion payout.
- **Unlocks** lists Unlock Walkers, Unlock Dog Slots, Unlock Dogs and Unlock Gear in that order. Each immediately grants the corresponding group in the save.
- Under **Money**, Add $100, Add $1,000 and Add $10,000 each immediately add their stated amount to the bank on every press.

Pocket item, Seed, Copy run link and Movement speed have no visible controls on the page. Existing browser-tab run links and test setup still support run overrides.

## Other actions

- **Reset save** stays visible at the end of the page. It is enabled only when available storage contains a valid saved checkpoint, a recorded ended walk, a positive bank balance or an earned badge. Default saves and hint-only changes do not qualify. Unavailable storage or newer-version data disables it. Reset requires confirmation, which Cancel and X can dismiss. Accepting immediately prevents repeat attempts, clears the save and earned badges, and keeps device settings.
